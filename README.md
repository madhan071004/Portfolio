# 🌐 Madhan M — Portfolio

A modern, responsive personal portfolio website built with **HTML**, **CSS**, and **JavaScript**. Showcasing my skills, projects, education, and contact information as a Java Full Stack Developer.


---

## ✨ Features

- 🎨 **Dark / Light Theme** — Toggle between elegant dark and clean light modes with smooth transitions
- ⌨️ **Typing Animation** — Dynamic hero section with rotating role titles
- 📱 **Fully Responsive** — Optimized for all screen sizes (mobile, tablet, desktop)
- 🧭 **Smooth Navigation** — Scroll spy, smooth scrolling, and auto-hiding navbar
- 📂 **Project Accordion** — Expandable project cards with descriptions, features, and links
- 🔍 **Project Filters** — Filter projects by category (All / Java Backend / Frontend React)
- 🎞️ **Scroll Animations** — Fade-up reveal animations using IntersectionObserver
- 📋 **Copy Email** — One-click email copy with toast notification
- ⬆️ **Back to Top** — Floating button appears on scroll

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/madhan071004/Portfolio.git
   cd Portfolio
   ```

2. **Open in browser**
   - Simply open `index.html` in any modern browser
   - Or use a local server:
     ```bash
     python -m http.server 8000
     ```
     Then visit `http://localhost:8000`
